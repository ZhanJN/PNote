# 变更记录

版本号规则：功能版本 + 小数点补丁（如 1.46.1 = 修 1.46 的缺陷）。当前 1.65.2。

## 1.65.2 — PEditor 引用 / 代码块 / 表格 / 跨块选择（2026-11-28）
- `[[笔记引用]]`：`/` 菜单与手机工具条都能插入；编辑时显示不带方括号的名字，
  单击直接打开那篇笔记；笔记源文件仍写 `[[名字]]`（不做数据迁移）
- 代码块：围栏代码升级为原生 `code` 块，带语言标签（如 DART）与语法着色；
  点块头或「编辑」弹窗能改语言和正文，写回仍是 ``` 围栏
- 表格：`/` 菜单插入 2×2 表格，表格右侧/底部「+」加行加列，单元格内可直接编辑
- `/` 菜单与手机工具条支持跨块选择/长按拖动（沿用上游块选择，手机长按选词后拖动扩选）
- `/` 菜单等内置文案改走中文（挂 `AppFlowyEditorLocalizations.delegate`）
- 新增 24 条测试，444 → 468 条
- 按用户要求：不做「353 篇往返 / 20 万字 / 保存不丢」门禁，以后也不再提
