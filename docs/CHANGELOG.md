# 变更记录

版本号规则：功能版本 + 小数点补丁（如 1.46.1 = 修 1.46 的缺陷）。当前 1.50.1。

## 1.50.1

- 发布流程：正式版目录只保留 `D:\PNote_V3`；归档副本改为「整体重建 + 逐文件 SHA-256 校验」（`tool/pack_archive.py`），不再用增量镜像
- 文档：新增发布与归档流程一节；`/MIR` 会把源目录残留搬进归档的教训入库
- 程序行为与 1.50 相同

## 1.50

- 代码结构重整（行为零变化）：`lib/` 根只留 `main.dart` / `app.dart`，其余按层归入 `theme/ ui/{shell,tasks,notes,trash,reminders,settings,devices,common} / data/ notes/ sync/ platform/`；项目内导入统一改用 `package:pnote/...`
- 64 个 Dart 文件、约 1.37 万行；测试仍 341 条全绿
- 打包为 `PNote_V3`

## 1.49

- 笔记的「彻底删除」也会同步：`.purge.json` 暂存 → 同步层盖 HLC 写入 `.sync.json` 的 `purged` → `notePurges` 帧；对端按文件名删正文、素材目录与回收站副本
- 同步成功提示统一为「本机已与 X 同步：…」，追加「彻底删除 N」
- 修：素材目录在正文被移入 `.trash` 后残留

## 1.48

- 笔记组：磁盘一级目录天然是组，另有 `.groups.json` 支持「一篇笔记属于多个组」；组清单是本机偏好，不同步
- 视图条：全部 → 各组 → 新建组 → 创建 ↑/↓、修改 ↑/↓ 四个时间视图（时间视图平铺、不显示月份标题、禁拖拽）
- 新建笔记仍落在「年/月」目录；在组视图里新建会同时加进该组

## 1.47

- 笔记进入同步通道（协议 `pnote-sync/6` → `/7`）：`.sync.json` 存文件版本，内容按 1 MB 分块传输，附件一并同步；同文件两边都改按 HLC 后改的赢
- 修：客户端首个 `state` 帧没带自己的笔记元信息导致对端 `want` 永远为空；服务端多帧并发导致 `.md.tmp` 未重命名

## 1.46 / 1.46.1

- 笔记列表支持长按拖拽排序（顺序存 `.order.json`）与「抬起/落定」同款动效；长按由列表层统一识别，避免误触打开
- 修「在文件夹中显示」：`explorer /select,` 必须拆成两个参数
- 1.46.1 修：交给资源管理器前必须把 relPath 的 `/` 归一成本机分隔符，否则 explorer 退回桌面

## 1.45

- 笔记多选与删除；统一回收站（一个页面，任务 / 笔记两个页签）；笔记行长按/右键菜单（打开、改标题、插入素材、在文件夹中显示、多选、删除）
- 修：素材目录名是「去掉 `.md` 的库内路径 + `.assets`」，且位于回收站桶内

## 1.44

- 编辑器大纲面板（点标题跳转）与 `[[笔记#小节]]` 锚点跳转；围栏代码块里的 `#` 不算标题

## 1.43

- 相对时间（「N 分钟前」）每 20 秒自检一次，跨分钟才刷新
- 反向链接面板、断链提示、字数统计；点不存在的 `[[x]]` 可直接新建

## 1.42

- 修「改标题」不生效：文件名、正文 `# 标题`、`[[旧名]]` 引用三处同时改
- 笔记库跟着程序目录走（正式版 `PNote_V3\PNote笔记库`），不再放在会被覆盖的 `pc\` 里
- 笔记页常驻「＋ 新建」按钮

## 1.41

- 笔记系统第一步：磁盘 Markdown 文件、`.assets` 素材、编辑即存、Markdown 渲染、搜索、回收站
- 数据仍与待办完全独立（不进任务库、不参与任务备份）

- 1.40 打包正式版目录 `PNote_V2`；1.39 修同步写整行漏写 `order_index`；1.38 逾期标红；1.37 本地提醒；1.36 自动归档与批量删除完成项；1.34/1.35 重复任务；1.33 组视图与内置字体；1.31 时间系统（schema 6）；1.24–1.30 两级分组、多选、回收站；1.17–1.23 双页签骨架、设置与主题、长按/拖拽/右键菜单
