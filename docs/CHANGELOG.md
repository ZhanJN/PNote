# 变更记录

版本号规则：功能版本 + 小数点补丁（如 1.46.1 = 修 1.46 的缺陷）。当前 1.63.4。

## 1.63.4 — 光标与操作区隔离（2026-11-28）
- 整块选择时排除选择条、底部工具条区域：点按钮不改选区、不启动贴边滚动
- 进入整块选择先把每块文字选区收成光标再失焦，列表光标切普通箭头，
  系统光标与 App 选区不再同时出现
- 长按取消阈值 3px → 1px：直接按住拖动只做文字选择
- 新增 1 条测试，420 → 421 条

## 1.63.3 — 删除当前行与光标修正（2026-11-28）

- 当前块按真实焦点定位：之前工具条用构建时捕获的 index，增删块后错位，
  「删除当前行」会删到下一行；现在先找 `focus.hasFocus` 的块
- 长按进入块选择的移动取消阈值 8px → 3px：直接拖拉选字不再被长按抢走
- 块首退格/块尾 Delete 只由 `_onHardwareKey` 处理一次，避免分割线删除后文字又被并一次
- 高亮底色改约 35% 半透明，深色主题下文字可读
- 测试 419 → 420 条

## 1.63.2 — 高亮按选区 + 光标跟手（2026-11-28）

- 高亮不再按层叠：选区里只要有一段没上色就整段上所选颜色（原有部分被覆盖）；全部上色
  且同色再点取消；全部上色但颜色不同用新色覆盖；选区外原有高亮保留
- 工具条操作后选区跟着文本走（加标记选中正文、取消选中原文），光标按标记长度平移，
  不再跳到块尾
- 普通点击不再重建块列表：点一次就聚焦、放光标，不用点第二次
- 测试 415 → 419 条

## 1.63.1 — 编辑器三修（2026-11-28）

- 修：嵌套格式（`**==重点==**` 等）编辑时露出内层标记；行内解析改为递归
- 修：彩色高亮再点高亮/换色会叠层；改为「有/无」开关，整层去掉
- 修：有序列表序号与文字不在同一条基线（字号/行高/上边距与正文统一）
- 修：手机上点「复制」时选区跳成按钮下那一块；选择条区域排除出选区判定，复制后保留选区
- 修：中文拼音组字期间光标/候选框串位；组字时编辑框退回纯文本渲染
- 调：长按进入块选择 450ms → 320ms，先于系统长按接管
- 测试 413 → 415 条

## 1.63 — 块编辑器热修（2026-11-28）

- 用户 m10031 的 BEQ：切模式/粘贴吞行、行占位消失、格式嵌套失效、空行后编号变 1.、
  双击高亮误伤、复制/剪切只取一块

  按行拆块且保留空行；编码跳过 `blank` 不重置编号；工具条用选区快照；选择态点
  选择条不移动指针、离开列表即停表
- 测试 409 → 413 条

## 1.51.0 — 初版（2026-11-24）

- 新增**账号名（同步分组）**：设置页可改本机名字，**同名设备才互相同步**，不同名的设备直接拒绝合并；名字只存本机（`meta.account_name`），不参与同步
- 内置「公开同步」账号：选了它的设备彼此同名，会在同一 Wi-Fi 内全量互相同步；选择时弹风险提示（会把任务与笔记同步给陌生设备）
- 切到「公开同步」时记住上一次的私有名（`meta.account_private_name`），打开对话框预填这个名字，点保存即可切回
- 协议升到 `pnote-sync/8`：`state` 帧新增 `account`，拒绝时 `ack` 也可带上本机账号，拨号方据此显示「账号不同（对方「X」）」而不是「协议不兼容」
- 发现广播的载荷同样带上账号名，连接设备页把不同账号的设备标出来
- 测试 341 → 354 条（账号名归一化、公开账号判定、跨账号拒绝、对话框预填与保存、设备页标记）
